JadwalKu Add-on for NVDA (Version 1.7.6.1)

JadwalKu is an advanced time management, agenda reminder, focus timer (Pomodoro), and periodic interval chime add-on that is 100% screen reader accessible and highly dynamic.

Global Shortcuts (Main Shortcuts)

  • NVDA + /: Enter the JadwalKu Command Layer. (See the key list below for advanced commands).
  • NVDA + Shift + /: Read Dynamic Status. NVDA will instantly iterate and read the remaining time of all currently active Timers, Alarms, and Pomodoro sessions simultaneously.
  • NVDA + F12 (1, 2, 3, times): Announce the current time, date, and countdown to the end of the current year.

Command Layer Mode (After Pressing NVDA + /)

After pressing NVDA + /, release the keys, then press one of the following keys to execute specific functions:

  • L or Enter or P: Open the Main Schedule Management & Settings Dialog.
  • 1: Open Quick Timer Manager. You can create a new timer, or Pause, Resume, and Stop if any timer is currently running.
  • 2: Open One-Time Alarm Manager with Pause/Resume capabilities.
  • 3: Open Pomodoro Timer (Focus, Short Break, Long Break, and Auto-Stop settings).
  • W: Announce the current time concisely.
  • K: Open Calendar & National Holidays List (Indonesian Red Dates).
  • D: Open World Clock & Timezone Converter Calculator.
  • J: Announce the next closest upcoming agenda for today along with its remaining time.
  • H: Announce all active agendas for today.
  • A: Toggle (Check/Uncheck) the periodic Time Reminder instantly.
  • S: Open Audio Manager to select sound output devices (Speakers) and adjust independent volume.
  • T: Open Independent TTS Manager (SAPI5) to configure background voice notifications.
  • R: Open the Bug Report/Feedback form (Directly connected to a Telegram Bot).
  • G: Share Add-on (Copy the direct download link to clipboard).
  • U: Check for JadwalKu Updates manually (Auto-Updater).
  • V: View Update History (Changelog).
  • Z: Snooze (Snooze currently ringing alarm/timer).
  • M: Enable Microphone monitoring (For voice commands).
  • Space: Stop (Stop the currently ringing notification/chime sound).
  • B or F1: Open the Help dialog (In-app comprehensive guide).
  • Escape: Cancel/Exit the JadwalKu Command Layer mode.

Key Features & Capabilities

  • Combo Box & Checkbox Interface: All settings are extremely screen reader friendly without the need to manually type time formats. Simply use the up/down arrows.
  • Sound Test Button (Alt + T): Inside the add agenda form, you can instantly test and listen to chime/alarm sound samples before saving.
  • Background Auto-Updater: JadwalKu is capable of checking for the latest version and downloading installation packages automatically and securely, without having to open an external browser.
  • Energy & Focus Management: Equipped with a Pomodoro timer and the ability to Pause any active timers so your schedule becomes much more flexible.

Add-on JadwalKu untuk NVDA (Versi 1.0.0)

JadwalKu adalah add-on manajemen waktu, pengingat agenda rutin (harian/mingguan), dan pengingat waktu berkala (hourly / interval chime) yang 100% ramah aksesibilitas screen reader.

Daftar Shortcut Utama

  • NVDA + Shift + J: Langsung membuka Dialog Utama Manajemen Jadwal & Pengaturan.
  • NVDA + /: Masuk ke Mode Perintah JadwalKu. Dalam mode ini, Anda dapat menekan tombol berikut:
    • L / Enter: Buka Dialog Utama Manajemen Jadwal.
    • W / T: Bacakan jam saat ini dan status pengingat waktu berkala.
    • J: Bacakan jadwal terdekat yang akan datang hari ini.
    • H: Bacakan daftar seluruh agenda aktif hari ini.
    • A: Check / Uncheck (Aktifkan / Nonaktifkan) pengingat waktu berkala secara cepat.
    • Spasi: Hentikan suara notifikasi/chime yang sedang berbunyi.
    • B / F1: Buka dialog Bantuan Read-Only yang dapat dibaca per baris dengan panah atas/bawah dan dieja dengan panah kiri/kanan.
    • Escape: Keluar dari mode JadwalKu.

Fitur & Kemampuan

  • Antarmuka Combo Box & Checkbox: Seluruh pengaturan dibuat menggunakan Combo Box (Dropdown) dan Checkbox yang sangat mudah dinavigasi dengan panah dan Spasi di NVDA tanpa perlu mengetik format waktu manual.
  • Tombol Tes Suara (Alt + T): Di dalam formulir tambah/edit agenda, Anda dapat langsung mencoba mendengarkan sampel suara chime/alarm sebelum menyimpan.
  • Dialog Bantuan Read-Only: Dilengkapi kotak teks multiline read-only yang nyaman dinavigasi menggunakan tombol panah layar NVDA.
  • Pembaruan Otomatis Tanpa Browser: Pengecekan versi latar belakang yang mengunduh dan memunculkan dialog pemasangan langsung dari dalam NVDA.

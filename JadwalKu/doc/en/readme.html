JadwalKu Add-on for NVDA (Version 1.7.6.5.2)

JadwalKu is an advanced time management add-on, habit tracker, agenda reminder, focus timer (Pomodoro), and hourly chime reminder that is 100% screen reader accessible and highly dynamic.

Global Shortcut List (Main Shortcuts)

  • NVDA + /: Enter the JadwalKu Command Layer Mode. (See the list of keys below for advanced commands).
  • NVDA + Shift + /: Announce Dynamic Status. NVDA will immediately calculate and announce the remaining time of all active Timers, Alarms, and Pomodoros simultaneously.
  • NVDA + F12 (1, 2, 3, times): Announce the current Time, Date, and countdown to the end of the current year.

Command Layer Mode (After Pressing NVDA + /)

After pressing NVDA + /, release it, then press one of the following keys to execute a specific function:

  • O or Enter or P: Open the Main Schedule Management & Settings Dialog.
  • J: Open the Habit Tracker to mark completed schedules.
  • L: Open the Badge Showcase (Persistence Scoreboard).
  • 1: Open the Quick Timer Manager. You can create a new timer, or Pause, Resume, and Stop an existing one.
  • 2: Open the One-Time Alarm Manager with Pause/Resume capabilities.
  • 3: Open the Pomodoro Timer (Focus, Short Break, Long Break, and Auto-Stop settings).
  • W: Announce a concise report of the current time and hourly chime status.
  • K: Open the Monthly Calendar & National Holidays List.
  • D: Open the World Clock & Time Zone Conversion Calculator.
  • H: Announce the entire list of active agendas for today.
  • I: Open the internal JadwalKu log file in Notepad for debugging/analysis.
  • A: Toggle Check/Uncheck the Hourly Time Reminder instantly.
  • S: Open the Audio Manager to select output devices (Speakers), set independent volumes, and toggle the Grandfather Clock.
  • T: Open the Standalone TTS Manager (SAPI5) to configure background notification voices.
  • R: Open the Submit Bug/Feedback Form (Directly connected to a Telegram Bot).
  • G: Share Add-on (Copy the direct download link to the clipboard).
  • U: Manually Check for JadwalKu Updates from the server (Auto-Updater).
  • V: Show the Update History (Changelog) dialog.
  • Z: Snooze a ringing alarm/timer for the next 10 minutes.
  • M: Toggle Microphone monitoring (For voice command mode).
  • Space: Stop (Stop a ringing notification/chime or turn off a ringing alarm clock).
  • B or F1: Open the Help dialog (Comprehensive in-app guide in read-only mode).
  • Escape: Cancel/Exit the JadwalKu Command Layer mode without taking action.

Additional Key Features & Capabilities

  • Habit Tracker & Badges (Gamification): JadwalKu now features a Habit Tracker (J) that awards you Persistence Badges (L) for every day you consistently complete your routine targets.
  • Combo Box & Checkbox Interface: All settings are designed to be extremely screen reader friendly without the need to manually type time formats. Simply use the up/down arrows.
  • Sound Test Button (Alt + T): Inside the agenda addition form, you can instantly listen to sample chime/alarm/TTS sounds before saving them.
  • Background Auto-Updater: JadwalKu can check for the latest versions and download installation packages automatically and securely, without opening an external browser.
  • Extreme Alarm Clock Mode: When you select the "Alarm Clock" mode, the sound will ring continuously without pause, interrupting TTS playback, until you physically press Space to stop it, or Z to snooze. Perfect for wake-up routines.
  • SAPI 5 Deadlock Protection: If you use Neural TTS online and your connection drops suddenly, JadwalKu will not hang but will automatically call NVDA as a backup voice within 2 seconds.
